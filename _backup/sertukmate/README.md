# AI 그림 맞히기 — "이거 뭐게?"

## 1. 앱 개요
- 내가 그림을 그리면 AI가 "이거 고양이네!" 하고 맞히는 게임
- 사용자: 그림 그리고 노는 걸 좋아하는 학생, AI랑 놀고 싶은 사람
- 목표: 제시어를 보고 그림을 그리면, AI가 보고 정답을 맞힌다. 맞히면 점수를 얻는다

## 2. 사용자와 권한
| 누구 | 할 수 있는 것 |
|---|---|
| 로그인 안 한 사람 | 그리기, AI 맞히기 (점수는 저장 안 됨) |
| 로그인한 사람 | 그리기, AI 맞히기, 내 점수·기록 저장 |

## 3. 기능 정의서
| 번호 | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 그리기 | 마우스·손가락으로 그림을 그린다 (색·굵기·지우개) | 필수 |
| F2 | 전체 지우기 | 캔버스를 깨끗이 지운다 | 필수 |
| F3 | 제시어 받기 | "고양이", "자동차" 같은 제시어를 하나 받는다 | 필수 |
| F4 | AI 맞히기 | 그림을 AI에게 보내 무엇인지 맞히게 한다 | 필수 |
| F5 | 정답 판정 | AI 답이 제시어와 맞으면 정답 🎉, 틀리면 땡 | 필수 |
| F6 | 점수 | 맞히면 점수가 오른다. 라운드마다 쌓인다 | 필수 |
| F7 | 회원가입·로그인 | 로그인하면 점수·기록을 저장한다 | 필수 |
| F8 | 내 기록 | 지난 라운드(제시어, AI 답, 맞음/틀림)를 본다 | 필수 |
| F9 | 그림 저장 | 그린 그림을 PNG로 내려받는다 | 선택 |
| F10 | 자유 모드 | 제시어 없이 아무거나 그리고 AI가 뭐로 보이는지 말해준다 | 선택 |

## 4. 화면
- 위: 제목, 점수, 닉네임, [로그인]/[로그아웃]
- 가운데: 그림판 (네모난 캔버스)
- 위쪽 띠: 지금 제시어("🎯 고양이를 그려보세요")
- 아래: 색·굵기·지우개, [전체 지우기]
- 큰 버튼: [AI야 맞혀봐!] / [다음 문제] / [저장]
- AI 답이 말풍선으로 나온다 ("음... 이건 고양이네요! (확신 85%)")
- 로그인·회원가입 화면, 내 기록 화면

## 5. 규칙과 예외 상황
- AI 키가 있으면 진짜 AI가 그림을 보고 맞힌다 (OpenAI 또는 Anthropic)
- AI 키가 없으면 "연습 모드"로 동작한다 (그림이 비었는지 등을 보고 간단히 추측 — 게임 흐름 체험용)
- 그림이 거의 비어 있으면 맞히기를 막고 "먼저 그려주세요"라고 안내한다
- 제시어는 미리 정해둔 안전한 단어 목록에서 고른다 (저작권·실존 인물 없음)
- 정답 판정은 AI 답에 제시어(또는 비슷한 말)가 들어 있으면 맞음으로 본다
- 점수·기록은 로그인한 사람만 저장한다
- 비밀번호는 해시로 저장한다. 닉네임은 글자 그대로 안전하게 보여준다(HTML 실행 안 됨)
- AI에 보내는 그림 크기는 적당히 줄여서(비용·속도) 보낸다

## 6. 저장할 데이터
- 회원: 아이디, 비밀번호 해시, 닉네임, 가입 시각
- 라운드 기록: 회원, 제시어, AI가 답한 것, 맞음/틀림, 얻은 점수, 시각

## 7. 완료 기준
- 제시어를 받고 그림을 그린 뒤 [AI야 맞혀봐!]를 누르면 AI(또는 연습 모드)가 답한다
- 맞히면 점수가 오르고, 로그인했으면 기록에 남는다
- 새로고침해도 로그인·점수·기록이 그대로다
- PC와 폰 모두에서 그릴 수 있다

## 8. AI 키 넣는 법 (나중에)
- `~/app/.env` 파일에 아래 중 하나를 넣으면 자동으로 진짜 AI로 바뀐다:
  - OpenAI: `OPENAI_API_KEY=sk-...`
  - Anthropic(Claude): `ANTHROPIC_API_KEY=sk-ant-...`
- 저장하면 앱이 저절로 다시 켜진다. 키가 없으면 연습 모드로 동작한다
