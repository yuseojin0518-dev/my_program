# 집중노트 — 공부 타이머 · 스터디 플래너 · 기록

## 1. 앱 개요
- 오늘 할 공부를 플래너에 적고, 뽀모도로 타이머로 집중해서 공부하고, 공부한 시간을 과목별·할 일별로 쌓아 보는 앱
- 사용자: 공부 습관을 만들고 싶은 중고등학생
- 목표: "오늘 무엇을 할지 → 얼마나 했는지"를 한눈에 보고, 매일 이어서 공부하게 돕는다

## 2. 사용자와 권한
| 누구 | 할 수 있는 것 |
|---|---|
| 로그인 안 한 사람 | 타이머 사용 (기록·플래너는 저장 안 됨) |
| 로그인한 사람 | 타이머, 스터디 플래너, 과목 관리, 공부 기록 저장, 통계, 하루 목표 설정 |

## 3. 기능 정의서
| 번호 | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 타이머 | 집중(15/25/50분)·짧은 휴식(5분)·긴 휴식(15분) 모드, 시작/일시정지/초기화 | 필수 |
| F2 | 자동 기록 | 집중 시간이 끝나면 고른 과목으로 기록이 저장된다 | 필수 |
| F3 | 중간 저장 | 집중 도중 멈춰도 1분 이상이면 그만큼 저장할 수 있다 | 필수 |
| F4 | 과목 관리 | 과목 추가(이름·색)·삭제. 처음엔 국어·수학·영어가 있다 | 필수 |
| F5 | 오늘 통계 | 오늘 공부한 시간과 하루 목표 달성률 | 필수 |
| F6 | 연속 공부일 | 하루도 안 빠지고 공부한 날 수 | 필수 |
| F7 | 주간 그래프 | 최근 7일 공부 시간 막대그래프 | 필수 |
| F8 | 과목별 비율 | 이번 주 과목별 공부 시간 | 필수 |
| F9 | 최근 기록 | 최근 기록 목록, 잘못된 기록 삭제 | 필수 |
| F10 | 직접 입력 | 타이머 없이 공부한 시간을 직접 기록 | 선택 |
| F11 | 알림 | 시간이 끝나면 소리와 브라우저 알림 | 선택 |
| F12 | 스터디 플래너 | 날짜별 할 일 적기(과목·목표 시간 선택), 완료 체크, 제목 고치기, 삭제 | 필수 |
| F13 | 할 일로 집중 | 할 일의 [집중]을 누르면 그 과목으로 타이머가 시작되고, 공부 시간이 그 할 일에 쌓인다 | 필수 |
| F14 | 미루기·가져오기 | 할 일을 내일로 옮기기, 지난 7일 동안 못 끝낸 할 일을 오늘로 한 번에 가져오기 | 필수 |
| F15 | 날짜 이동 | 앞뒤 일주일 날짜 줄(할 일 있는 날 점 표시), 일주일씩 이동, [오늘로] | 필수 |

## 4. 화면
- 위: 앱 이름, [타이머]/[플래너]/[기록] 탭, 닉네임, [로그인]/[로그아웃]
- 타이머 탭 (위에서 아래로)
  - 로그인 안 했으면: "로그인하면 기록돼요" 안내 띠와 [로그인] 버튼
  - 로그인했으면: 오늘 공부량 / 목표 막대와 오늘 할 일 완료 수 (누르면 기록 탭)
  - 모드 버튼(집중·짧은 휴식·긴 휴식), 집중 길이(15/25/50분)
  - 가운데 원형 타이머 (안에 지금 과목 이름, 연결된 할 일 이름)
  - 상황에 맞는 버튼만 보임: 처음엔 [집중 시작] / 도는 중 [일시정지]·[여기까지 저장] / 멈춤 [계속하기]·[처음으로] / 휴식 [휴식 건너뛰기]
  - 할 일과 연결돼 있으면 "할 일 ○○ 하는 중" 띠와 [연결 끊기]
  - 과목 버튼(눌러서 고름, [+ 과목 추가]로 그 자리에서 추가), 메모
  - "끝나면 다음 단계 자동 시작" 체크, 스페이스바 단축키 안내, [직접 기록하기]
- 플래너 탭 (위에서 아래로)
  - 날짜 줄(앞뒤 3일, 할 일 있으면 점: 다 끝냈으면 초록, 남았으면 주황), ‹ › 로 일주일 이동
  - 날짜 제목("오늘 · 10월 11일 (일)"), 완료 수와 할 일로 공부한 시간, 완료 막대, [오늘로]
  - 오늘이고 지난 7일에 못 끝낸 일이 있으면 [오늘로 가져오기] 안내
  - 할 일 입력 칸(Enter로 추가, 바로 다음 것 이어서 입력), 과목 버튼(다시 누르면 해제), 목표 시간
  - 할 일 목록: 체크박스, 제목(눌러서 고치기), 과목·공부시간/목표·진행 막대, [집중]·[내일로]·[삭제]. 끝낸 일은 아래로 내려가고 줄이 그어진다
- 기록 탭: 오늘·목표, 연속일, 이번 주 합계 카드 → 주간 막대그래프 → 과목별 막대 → 최근 기록 목록
- 과목 편집 창, 직접 기록 창(빠른 시간 버튼), 하루 목표 창(빠른 목표 버튼), 로그인·회원가입 창

## 5. 규칙과 예외 상황
- 시간과 날짜는 한국 시간(Asia/Seoul) 기준으로 센다 (서버는 UTC로 저장)
- 기록 한 번은 1~300분, 하루 목표는 10~720분
- 과목은 20개까지, 이름 1~20자, 같은 이름 중복 불가
- 과목을 지워도 그 과목의 기록과 할 일은 "과목 없음"으로 남는다
- 새로고침해도 돌아가던 타이머는 이어서 돌아간다. 고른 과목, 연결된 할 일, 자동 시작 설정도 기억한다
- 타이머가 도는 동안은 모드·시간을 바꿀 수 없다 (실수 방지). 멈춘 상태에서 1분 넘게 한 시간을 버리게 되면 먼저 물어본다
- "여기까지 저장"은 로그인하고 집중을 1분 넘게 했을 때만 보인다
- 집중을 4번 끝내면 긴 휴식, 그 외엔 짧은 휴식으로 넘어간다
- 로그인 안 하고 타이머를 끝내면 "로그인하면 저장돼요" 안내만 한다
- 할 일은 1~60자, 하루 30개까지, 목표 시간은 0~600분(0이면 목표 없음)
- 할 일에 쌓이는 시간은 그 할 일에서 시작한 타이머 집중만 센다 (직접 기록은 할 일에 안 붙는다)
- 할 일 [집중]을 누를 때 이미 집중이 돌고 있으면, 그 시간을 이 할 일로 이어서 기록할지 묻는다. 쉬는 중이면 휴식을 멈추고 집중을 시작한다
- 연결된 할 일이 목표 시간을 채우면 집중 끝 알림에서 알려 준다. 완료를 체크하거나 지우면 타이머 연결이 풀린다
- 할 일을 지워도 공부 기록은 남는다
- 비밀번호는 해시로 저장, 사용자가 쓴 글은 HTML로 실행되지 않게 보여준다

## 6. 저장할 데이터
- 회원: 아이디, 비밀번호 해시, 닉네임, 하루 목표(분), 가입 시각
- 과목: 회원, 이름, 색
- 할 일: 회원, 날짜(한국 날짜), 제목, 과목, 목표 시간(분), 완료 여부, 순서, 만든 시각
- 공부 기록: 회원, 과목, 할 일, 공부 시간(분), 방식(타이머/직접 입력), 메모, 끝난 시각

## 7. 완료 기준
- 집중 타이머가 끝나면 기록 탭의 오늘 시간·그래프·최근 기록에 바로 반영된다
- 플래너에서 할 일의 [집중]으로 공부하면 그 할 일의 공부 시간이 바로 늘어난다
- 어제 못 끝낸 할 일을 오늘로 가져올 수 있다
- 새로고침해도 로그인·기록·할 일·돌아가던 타이머가 유지된다
- PC와 폰에서 모두 쓰기 편하다
