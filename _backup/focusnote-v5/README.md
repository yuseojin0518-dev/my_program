# 집중노트 — 공부 타이머 · 스터디 플래너 · 기록 · 공부 도구

## 1. 앱 개요
- 오늘 할 공부를 플래너에 적고, 뽀모도로 타이머로 집중해서 공부하고, 공부한 시간을 과목별·할 일별로 쌓아 보는 앱
- 사용자: 공부 습관을 만들고 싶은 중고등학생
- 목표: "오늘 무엇을 할지 → 얼마나 했는지"를 한눈에 보고, 매일 이어서 공부하게 돕는다

## 2. 사용자와 권한
| 누구 | 할 수 있는 것 |
|---|---|
| 로그인 안 한 사람 | 타이머 사용 (기록·플래너는 저장 안 됨) |
| 로그인한 사람 | 타이머, 스터디 플래너, 과목 관리, 공부 기록 저장, 통계, 하루 목표 설정, 시간표, 단어장, 오답노트 |

## 4. 화면
- 디자인은 Apple 휴먼 인터페이스 가이드라인(HIG)의 원칙을 참고한다: 화면마다 큰 제목, 한 화면에 가장 중요한 버튼 하나, 묶음 목록, 시스템 색, 다크 모드, 손가락으로 누르기 쉬운 크기(44px 이상)
  - Apple 로고·SF Symbols 아이콘·SF 글꼴 파일은 쓰지 않는다. 아이콘은 직접 그리고, 글꼴은 기기 기본 글꼴을 쓴다
- 위: 앱 이름, [타이머]/[플래너]/[기록]/[도구] 탭(아이콘+글자), 화면 밝기 버튼, 닉네임, [로그인]/[로그아웃]
  - 폰(좁은 화면)에서는 탭이 화면 맨 아래 탭 막대로 내려가고, 창은 아래에서 올라오는 시트로 열린다
- 타이머 탭 (위에서 아래로)
  - 로그인했으면: D-day 줄(가까운 것 3개, [+]로 관리)
  - 로그인 안 했으면: "로그인하면 기록돼요" 안내 띠와 [로그인] 버튼
  - 로그인했으면: 오늘 공부량 / 목표 막대와 오늘 할 일 완료 수 (누르면 기록 탭)
  - 모드 버튼(집중·짧은 휴식·긴 휴식), 집중 길이(15/25/50분)
  - 가운데 원형 타이머 (안에 지금 과목 이름, 연결된 할 일 이름)
  - 상황에 맞는 버튼만 보임: 처음엔 [집중 시작] / 도는 중 [일시정지]·[여기까지 저장] / 멈춤 [계속하기]·[처음으로] / 휴식 [휴식 건너뛰기]
  - 도구 줄: [크게 보기], 배경 소리(끔·백색소음·빗소리·웅성웅성)와 소리 크기
  - 할 일과 연결돼 있으면 "할 일 ○○ 하는 중" 띠와 [연결 끊기]
  - 과목 버튼(눌러서 고름, [+ 과목 추가]로 그 자리에서 추가), 메모
  - "끝나면 다음 단계 자동 시작" 스위치, 스페이스바 단축키 안내, [직접 기록하기]
- 플래너 탭 (위에서 아래로)
  - 제목 옆 [주]/[달력] 보기 바꾸기 (고른 보기는 기억한다)
  - 주 보기: 날짜 줄(앞뒤 3일, 할 일 있으면 점: 다 끝냈으면 초록, 남았으면 주황), ‹ › 로 일주일 이동
  - 달력 보기: "2026년 10월" 제목, [오늘]·‹ › 로 달 이동, 일요일부터 시작(일요일 빨강·토요일 파랑), 날마다 할 일 점·D-day 빨간 점과 이름·공부 시간, 아래에 점 설명. 날짜를 누르면 그날 할 일이 아래에 나온다
  - 날짜 제목("오늘 · 10월 11일 (일)"), 완료 수와 할 일로 공부한 시간, 완료 막대, [오늘로]
  - 오늘이고 지난 7일에 못 끝낸 일이 있으면 [오늘로 가져오기] 안내
  - 할 일 입력 칸(Enter로 추가, 바로 다음 것 이어서 입력), 과목 버튼(다시 누르면 해제), 목표 시간
  - 할 일 목록: 체크박스, 제목(눌러서 고치기), 과목·공부시간/목표·진행 막대, [집중]·[내일로]·[삭제]. 끝낸 일은 아래로 내려가고 줄이 그어진다
- 기록 탭: 오늘·목표, 연속일, 이번 주 합계 카드 → 주간 막대그래프 → 공부 잔디(12주) → 과목별 막대 → 최근 기록 목록과 [엑셀로 받기]
- 집중 화면: 어두운 배경에 큰 시계, 지금 하는 과목·할 일, 진행 막대, [시작/일시정지], [닫기] (스페이스바·Esc 사용)
- 도구 탭: [시간표]/[단어장]/[오답노트] 고르기
  - 시간표: 표, [− 교시]/[+ 교시], 자주 쓰는 과목 버튼
  - 단어장: 단어장 목록(카드 수·오늘 외울 수·[외우기]) → 단어장 안: [오늘 외우기]/[전부 외우기], 카드 여러 줄 입력, 카드 목록(단계 표시)
  - 외우기 화면: 진행 막대, 큰 카드(눌러서 뒤집기), [몰라요]/[알아요], 끝나면 결과 (스페이스·←·→·Esc 사용)
  - 오답노트: [오늘 볼 것]/[안 푼 것]/[해결], 과목 거르기, [+ 오답 적기], 오답 목록(정답은 숨겼다가 눌러서 보기, [또 틀림]/[맞혔어요]/[고치기]/[삭제])
- 과목 편집 창, D-day 창, 화면 밝기 창, 오답 적기 창, 직접 기록 창(빠른 시간 버튼), 하루 목표 창(빠른 목표 버튼), 로그인·회원가입 창

## 5. 규칙과 예외 상황
- 시간과 날짜는 한국 시간(Asia/Seoul) 기준으로 센다 (서버는 UTC로 저장)
- 기록 한 번은 1~300분, 하루 목표는 10~720분
- 과목은 20개까지, 이름 1~20자, 같은 이름 중복 불가
- 과목을 지워도 그 과목의 기록과 할 일은 "과목 없음"으로 남는다
- 새로고침해도 돌아가던 타이머는 이어서 돌아간다. 고른 과목, 연결된 할 일, 자동 시작 설정도 기억한다
- 타이머가 도는 동안은 모드·시간을 바꿀 수 없다 (실수 방지). 멈춘 상태에서 1분 넘게 한 시간을 버리게 되면 먼저 물어본다
- "여기까지 저장"은 로그인하고 집중을 1분 넘게 했을 때만 보인다
- 집중을 4번 끝내면 긴 휴식, 그 외엔 짧은 휴식으로 넘어간다
- 로그인 안 하고 타이머를 끝내면 "로그인하면 저장돼요" 안내만 한다
- 할 일은 1~60자, 하루 30개까지, 목표 시간은 0~600분(0이면 목표 없음)
- 할 일에 쌓이는 시간은 그 할 일에서 시작한 타이머 집중만 센다 (직접 기록은 할 일에 안 붙는다)
- 할 일 [집중]을 누를 때 이미 집중이 돌고 있으면, 그 시간을 이 할 일로 이어서 기록할지 묻는다. 쉬는 중이면 휴식을 멈추고 집중을 시작한다
- 연결된 할 일이 목표 시간을 채우면 집중 끝 알림에서 알려 준다. 완료를 체크하거나 지우면 타이머 연결이 풀린다
- 할 일을 지워도 공부 기록은 남는다
- D-day는 10개까지, 이름 1~20자. 오늘이면 "D-DAY", 지난 날은 "D+3"처럼 보이고 위 줄에는 안 나온다
- 배경 소리는 앱이 직접 만든 잡음이라 음악 파일·저작권이 필요 없다. 집중 타이머가 도는 동안만 나고, 멈추거나 쉬면 꺼진다
- 공부 잔디 진하기: 0분 / 30분 미만 / 90분 미만 / 3시간 미만 / 3시간 이상
- 엑셀 파일은 한글이 깨지지 않게 저장하고, 메모가 '=' 같은 기호로 시작해도 엑셀에서 수식으로 실행되지 않게 막는다
- 시간표 칸 이름은 12자까지. 오늘 수업 알림은 월~금에만 나온다
- 단어장은 30개, 단어장 하나에 카드 500장까지. 앞면 100자·뒷면 200자. 뒷면이 없는 줄은 빼고 알려 준다
- 오답은 1000개까지, 문제 500자. 과목을 지워도 오답은 '과목 없음'으로 남는다
- 비밀번호는 해시로 저장, 사용자가 쓴 글은 HTML로 실행되지 않게 보여준다

## 6. 저장할 데이터
- 회원: 아이디, 비밀번호 해시, 닉네임, 하루 목표(분), 가입 시각
- 과목: 회원, 이름, 색
- 할 일: 회원, 날짜(한국 날짜), 제목, 과목, 목표 시간(분), 완료 여부, 순서, 만든 시각
- 공부 기록: 회원, 과목, 할 일, 공부 시간(분), 방식(타이머/직접 입력), 메모, 끝난 시각
- D-day: 회원, 이름, 날짜(한국 날짜)
- 시간표: 회원, 요일, 교시, 과목 이름
- 단어장: 회원, 이름 / 카드: 단어장, 앞면, 뒷면, 단계(1~5), 다음 복습 날짜
- 오답: 회원, 과목, 출처, 문제, 정답·풀이, 틀린 이유, 다시 볼 날짜, 맞힌 횟수, 해결 여부
- 브라우저에만 저장: 돌아가던 타이머, 고른 과목, 연결된 할 일, 자동 시작, 배경 소리 종류와 크기, 플래너 보기 방식(주/달력), 화면 밝기

## 7. 완료 기준
- 집중 타이머가 끝나면 기록 탭의 오늘 시간·그래프·최근 기록에 바로 반영된다
- 플래너에서 할 일의 [집중]으로 공부하면 그 할 일의 공부 시간이 바로 늘어난다
