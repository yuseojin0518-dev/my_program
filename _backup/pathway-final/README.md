# Pathway — 고등학생 학업 내비게이션

## 1. 앱 개요
- 한 줄: **진로 목표에서 오늘 할 공부까지 한 번에 이어 주는 앱**
- 문제: 시험 계획은 세우지만 밀리면 포기한다. 어느 과목에 시간을 얼마나 써야 하는지 근거가 없다.
- 해결: 목표 등급을 **거꾸로 계산**(기말 몇 점?) → 평균등급을 가장 많이 내리는 과목에 **시간을 배분** → 계획마다 **"왜?"를 숫자로 설명** → 못 지키면 **자동 재조정**
- 사용자: 고등학생 (고교학점제 5등급제, 2024년 이전 입학 9등급제 모두)

## 2. 데이터 흐름 (핵심)
```
진로 목표 → 선택과목 조합 → 내신 목표 점수 역산 → 일별 공부 계획
     ↑                                                    │
     └──────── 공부 기록·시험 결과로 다시 계산 ←──────────┘
```
- 진로가 교과 비중(예: AI공학 → 수학·정보 ×1.4)을 정해 시간 배분과 과목 추천에 들어간다
- 지금 예상 성적(교과별 위치)이 선택과목 추천의 '내신 유리' 점수로 들어간다
- 고른 조합은 다음 학기 과목으로 성적 시뮬레이터에 넣을 수 있다
- 시험 결과를 넣으면 과목마다 공부 효율을 보정해 다음 계획에 반영한다

## 5. 화면
- 디자인: 토스 스타일 **한 화면 한 질문 + 굵은 글자**
  - 홈(대시보드)은 선 없는 흰 카드로 요약, 맨 위에 오늘 할 일을 한 문장으로 ("오늘은 2시간 공부하면 돼요") + 버튼 하나
  - 무언가를 입력하는 순간(처음 시작, 공부 기록, 시간 고치기, 중간고사 점수, 시험 결과, 과목 추가, 공부 가능 시간)은 한 화면에 질문 하나, 맨 아래 꽉 찬 파란 버튼 하나. 고르는 질문은 누르면 바로 다음으로
  - 글자 위계: 제목 #191F28 굵게 / 본문 #333D4B / 설명 #8B95A1. 구분선 대신 여백과 글자 굵기로 나눔
  - 말투는 대화체 ("몇 점 받았나요?", "기록하기"), 끝 화면은 체크 표시가 튀어나오는 움직임
  - 글꼴 Pretendard(무료 글꼴), 밝게/어둡게, 누르는 곳 44px 이상
- 그래프: 회색 통 = 계획, 연한 파랑 = 실제, 오늘만 진한 파랑. 과목 색은 눈이 편한 중간 채도, 공부 잔디도 파란 계열
- 휴대폰: 아래 탭 막대 5개, 오늘 할 일 버튼은 탭 막대 위에 고정 / 넓은 화면: 왼쪽 사이드바(메뉴 + 요약) + 12칸 격자
- 처음 화면: 소개, 체험 학생 실제 계산 미리보기, 6가지 기능, 숫자 띠, 계산 방법 3단계, 2분 시연 순서, 자주 묻는 질문
- 탭: 대시보드 · 진로·과목 · 성적 · 계획 · 리포트

## 6. 계산 규칙
- 등급: 5등급제 누적 10/34/66/90/100%, 9등급제 4/11/23/40/60/77/89/96/100%. 원점수 경계 = 평균 + 표준편차 × Φ⁻¹(1 − 누적 비율)
- 성취도: A 90 / B 80 / C 70 / D 60 이상. 학업성취율 40% 미만이면 미이수 위험 표시
- 예상 등급: 아직 안 본 시험의 운(반영 비율의 8%)과 난이도 변화(2점)를 정규분포로 보고 등급마다 확률을 더한 기댓값
- 공부 효과: 점수(H) = 100 − (100 − 지난 점수) × 0.6^((H − 지난 공부 시간) ÷ 범위 한 번 공부 시간). 지난 점수의 절반 아래로는 안 떨어진다고 본다
- 과목 무게 = 학점 × 진로 비중 × (성취도만 나오는 과목 0.5). 등급 없는 과목(체육·예술·교양)은 계획에 넣지 않는다
- 배분: 과목마다 최소 학점×30분 → 30분~16시간 덩어리 중 시간당 이득이 가장 큰 곳에 → 교환으로 다듬기. 시험이 빠른 과목들 시간 합 ≤ 그 시험 전날까지 공부 가능 시간
- 계획표: 날마다 꼭 해야 하는 양 먼저, 나머지는 '남은 양 ÷ 남은 시간'이 큰 과목. 한 과목은 하루의 절반까지. 여유 시간은 시험에서 먼 날에 남긴다
- 시험 결과 보정: 실제 점수가 '몇 번 공부한 효과'였는지 거꾸로 구해 효율 배율을 고친다 (한 번에 반쯤만, 0.4~2.5배)
- 선택과목 점수 = 학점 × (α·진로 적합 + (1−α)·내신 유리). 진로 적합: 핵심 1, 권장 0.65, 그 외 교과 비중. 내신 유리: 지금 교과 위치와 수강자 수로 정한 예상 등급 (성취도만 0.85, 등급 없음 0.6)
- 가지치기: 졸업 요건을 남은 묶음으로 못 채움 / 이미 듣거나 겹치는 과목 / 선수 과목 없음 / 꼭 들을 과목이 남은 묶음에 없음 / 남은 묶음 최고 점수(겹치는 과목까지 넣은 DP)를 더해도 5위 안에 못 듦
- 졸업 요건: 교과 174학점, 국어·수학·영어 8, 사회 16, 과학 10, 체육 10, 예술 10, 생활·교양 16
- 날짜는 한국 시간 기준

## 7. 보안·예외
- 비밀번호는 bcrypt 해시, 로그인·가입·설문은 요청 수 제한, 상태를 바꾸는 요청은 JSON만 받음
- 저장할 때 버전을 확인해 다른 기기 데이터를 덮어쓰지 않음 (충돌하면 고르게 함)
- SQL은 `?` 자리표시자, 사용자 글은 화면에 글자로만 표시
- 나이스가 안 되면 오류 대신 직접 입력 안내. 응답은 12시간(학교 검색 7일) 캐시. 인증키가 없으면 기간을 잘게 나눠 부름 (`.env`에 `NEIS_API_KEY`를 넣으면 더 빠름)
- 3학년 편성표와 진로별 권장 과목은 시연용 예시

## 8. 저장할 데이터
- 서버(SQLite): 회원(아이디·비밀번호 해시·닉네임), 내 데이터(JSON 한 덩어리·버전), 나이스 캐시, 익명 사용 기록, 설문
- 내 데이터: 프로필(진로·학교·학년·등급제·설정), 학기별 과목(학점·평가 방식·평균·표준편차·수강자·목표·지난 점수·공부 시간·효율·단원·점수 구성), 공부 가능 시간, 학사일정, 들은 과목, 선택과목 선호·고른 조합, 계획, 공부 기록, 오답 노트, 시험 결과, 계획 바뀐 기록
- 브라우저: 손님 데이터, 화면 밝기, 집중 타이머

## 9. 완료 기준
- 처음 온 사람이 30초 안에 첫 계획을 본다 (실제 시간은 리포트의 '첫 계획까지' 숫자)
- 슬라이더를 움직이면 등급·확률·계획 미리보기가 바로 바뀐다
- 하루를 안 지키고 넘기면 다음에 들어올 때 계획이 자동으로 다시 짜이고, 모든 계획이 시험 전에 끝난다
- 최적 배분은 어느 과목에서 어느 과목으로 옮겨도 더 좋아지지 않는다 (시험으로 확인)
- 가지치기한 조합 탐색 결과가 완전 탐색과 같다 (시험으로 확인)
- 휴대폰·PC 모두에서 오류 없이 쓴다
