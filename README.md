# EduSpace — 우리 반 올인원 협업 공간

## 1. 앱 개요
- 한 줄: **나이스 학사 데이터(학사일정·급식) + 실시간 학급 협업(공유 달력·클래스룸·문서함·공유 노트)을 한 화면에**
- 문제: 학사일정은 학교 홈페이지, 수행평가 마감은 단톡방, 자료는 여기저기 흩어져 있다
- 해결: 학교·학년·반을 정하면 학교 공식 일정과 급식이 자동으로 들어오고, 반 친구들과 일정·아이디어·파일·노트를 실시간으로 함께 관리
- 사용자: 고등학생과 선생님

## 2. 사용자와 권한
| 누구 | 할 수 있는 것 |
|---|---|
| 학생 | 내 반: 일정 추가·수정, 공지·문서·노트 쓰기, 댓글, 과제 제출. 같은 학교 다른 반: **보기만** |
| 선생님 (`.env`의 `TEACHER_CODE` 필요, 체험 선생님 버튼도 있음) | 같은 학교 모든 반에 쓰기, 과제·질문·자료 만들기, 채점·반환, 남의 글·파일 지우기 |
| 글쓴이 | 내 일정·공지·문서·노트·댓글 지우기 |
- 일정과 노트 내용은 반 누구나 고칠 수 있다 (함께 관리). 노트·문서를 **지우는 것은 만든 사람과 선생님만** (목록과 상세 화면의 🗑)

## 3. 화면 (3단 구조)
- **왼쪽 사이드바**: 프로필, 학년·반 바꾸기(다른 반은 보기만), 메뉴 4개, 지금 접속한 친구, **오늘의 급식**(중식/석식, 날짜 넘기기, 칼로리, 알레르기 번호), **이번 주 일정**
- **가운데**: 고른 메뉴 화면
- **오른쪽 패널**: 일정·문서·학생 제출물을 누르면 페이지 이동 없이 오른쪽에서 열림 (상세·수정·첨부·댓글)
- 휴대폰: 사이드바는 ☰ 메뉴, 아래에 탭 4개, 달력 위에 급식 카드
- 디자인: 토스 스타일(흰 카드, 굵은 글자 위계, 둥근 모서리, 큰 버튼), Pretendard 글꼴(무료). 로그인은 한 화면에 질문 하나

## 5. 규칙과 예외
- 학급 = 교육청-학교-학년-반. 같은 학교만 볼 수 있고, 쓰기는 내 반(선생님은 학교 전체)만
- 상태를 바꾸는 요청은 화면이 붙이는 머리글(`X-ES`)이 있어야 받음, 쿠키는 SameSite=Lax → 다른 사이트에서 몰래 보내는 요청 차단
- SQL은 `?` 자리표시자, 사용자 글은 화면에 글자로만 표시(마크다운도 HTML 막음)
- 파일: 10MB, PDF·한글·워드·PPT·엑셀·사진·텍스트·ZIP만. 같은 학교 로그인한 사람만 받을 수 있음. 사진·글 파일은 스크립트가 실행되지 않게 막아서 보여 줌
- 요청 수 제한: 로그인, 올리기, 댓글, 카드
- 나이스 키가 없으면 한 번에 5건만 와서 기간을 잘게 나눠 부른다 (`.env`에 `NEIS_API_KEY`를 넣으면 빠르고 시간표 등도 다 옴). 응답은 학사일정 12시간·급식 6시간·학교 검색 7일 캐시
- 빠른 로그인은 비밀번호가 없다. **같은 학교·학년·반·역할·이름이면 같은 사람(한 계정)** 으로 들어간다 → 여러 번 들어와도 한 명. (비밀번호가 없어 같은 반에서 이름을 아는 사람은 그 계정으로 들어올 수 있다.) 체험 계정은 '체험 학생' 하나·'체험 선생님' 하나를 함께 쓴다. 예전에 겹쳐 만들어진 계정은 서버가 켜질 때 하나로 합친다 (글·제출물도 옮김)
- 체험 반(춘천고 2학년 1반)의 친구 이름·글·파일은 시연용 예시

## 6. 데이터 (SQLite `app.db`, 파일은 `uploads/`)
- `es_users` 사용자(이름·역할·이메일·학교·학년·반·색) / `es_subjects` 과목 / `es_events` 반 일정(사진·첨부 id 목록, 만든·고친 사람)
- `es_posts` 스트림 공지 / `es_cw` 수업 과제(과제·질문·자료, 주제·점수·마감·첨부·질문 형식) / `es_subs` 제출물(학생·글·첨부·답·제출·반환 시각·점수) / `es_docs`·`es_doc_versions` 문서와 버전
- `es_notes` 노트(쪽마다 모양 목록, 예전 글 노트는 첫 쪽 글상자로 옮김) / `es_study` 공부 기록(사람·반·과목·날짜·시작·마지막 알림·초) / `es_ink` 손필기(쪽·펜 종류·색·굵기·점 [x, y, 필압] / 글상자 / 사진, 쪽 크기 1000×1414) / `es_comments` 댓글(일정·문서·공지·과제·🔒제출물) / `es_files` 올린 파일 / `es_neis_cache` 나이스 캐시
- 브라우저: 지금 보는 반, 문서 보기·노트 보기 방식, 펜 설정

- PDF 가져오기·내보내기는 PyMuPDF(1.24.14)를 쓴다

## 7. 설정 (`.env`)
- `SECRET_KEY` 세션 비밀키, `TEACHER_CODE` 교사 코드, (선택) `NEIS_API_KEY`, `GOOGLE_CLIENT_ID`·`GOOGLE_CLIENT_SECRET` (구글 콘솔의 승인된 리디렉션 주소: `https://<주소>/auth/google/callback`)

## 8. 완료 기준
- 두 사람이 같은 노트에 동시에 써도 두 화면이 같은 글이 된다 (시험으로 확인)
- 한 사람이 일정을 추가하면 다른 사람 달력에 새로고침 없이 뜬다 (시험으로 확인)
- 다른 반은 보기만, 다른 학교는 볼 수 없다 (시험으로 확인)
- 나이스가 안 돼도 화면이 비지 않는다 (예시 데이터)
- 한 사람이 펜으로 그리거나 지우거나 올가미로 옮기거나 쪽을 넣으면 다른 사람 노트에 바로 보인다 (시험으로 확인)
- 학생이 과제를 내면 선생님이 채점·반환하고, 학생 화면에 바로 점수가 뜬다 (시험으로 확인)
- 휴대폰·PC·아이패드 모두 오류 없이 쓴다

## 9. 시험 방법
- 동시 편집 엔진: `cd ~/app && node --test tests/js` (무작위 동시 편집 3000번 + 서버·학생 3명 흉내 60번)
- 서버: `cd ~/app && python -m pytest -q tests` (12개: 같은 정보 한 계정·계정 합치기, 공부 타이머·순위·자동 멈춤, 노트·문서 지우기 권한, 권한, 로그인, 파일, 문서 버전, 클래스룸 제출·채점·반환·비공개 댓글, 노트 동시 편집, 손필기·쪽·PDF 가져오기·내보내기, 나이스 예시)
- 화면(진짜 브라우저 세 개 = 학생 두 명 + 선생님): `cd ~/app && python tests/ui_smoke.py` → 스크린샷 `tests/shots/`
